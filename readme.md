# PurpleKnightDashboard

Generates an HTML dashboard to review the evolution of Purple Knight scores and indicators of exposure using the HTML reports generated by [Purple Knight](https://www.purple-knight.com).

This project is the Purple Knight equivalent of [leobouard/PingCastleDashboard](https://github.com/leobouard/PingCastleDashboard).

**This script requires the module `PSWriteHTML`.** You can install the module through PSGallery using `Install-Module PSWriteHTML`. More information about this module here: <https://github.com/EvotecIT/PSWriteHTML>

## How to use it?

The project contains two scripts:

1. `PurpleKnightDashboard.ps1` to create one dashboard per forest
2. `PurpleKnightGlobalDashboard.ps1` to create a centralized dashboard for up to 10 forests

Both scripts share the code of `Functions.ps1`, which must stay in the same folder.

### PurpleKnightDashboard.ps1

Copy the HTML reports generated by Purple Knight (`Security_Assessment_Report_*.html`) in the `reports` folder and execute the script. A file picker opens in the `reports` folder: select the reports to compare (for example the old and the new one) and one dashboard will be generated for each forest in the `output` folder.

```powershell
.\PurpleKnightDashboard.ps1
```

To use all the reports of a folder without the file picker, use the `-ReportPath` parameter:

```powershell
.\PurpleKnightDashboard.ps1 -ReportPath '.eports'
```

The content of the `reports` folder is ignored by git, so your reports are never committed.

| Parameter          | Description                                                        | Default                         |
| ------------------ | ------------------------------------------------------------------ | ------------------------------- |
| `-ReportPath`      | Folder containing the Purple Knight HTML reports (recursive)       | File picker in `.eports`      |
| `-OutputPath`      | Folder where the dashboards are written                            | `.\output`                      |
| `-DateFormat`      | Date format used for tab names and table columns                   | `yyyy-MM-dd`                    |
| `-Logo`            | URL of a logo displayed in the header                              | Text "Purple Knight dashboard"  |
| `-URI`             | Link opened when clicking on the logo                              | `https://www.purple-knight.com` |
| `-Author`          | Author of the HTML document                                        | `PurpleKnightDashboard`         |
| `-MaxWidth`        | Maximum width of the dashboard (in pixels)                         | `1400`                          |
| `-DoNotShow`       | Do not open the dashboard once generated                           |                                 |
| `-InvertChartLine` | Reverse the Y axis of the "risk points" and "exposures" charts     |                                 |

### PurpleKnightGlobalDashboard.ps1

Same as `PurpleKnightDashboard.ps1`: select the reports (or use `-ReportPath`) and execute `PurpleKnightGlobalDashboard.ps1` to create a centralized dashboard (`output\dashboard_global.html`) for up to 10 forests. Only the last report of each month is kept for each forest.

## What's in the dashboard?

**Home tab**

- Improvement & deterioration between the first and the last report: new exposures (with their first appearance) and exposures resolved (with their last appearance)
- Evolution of the Purple Knight security score, total risk points, ANSSI maturity level and exposures per severity
- Evolution of the score of each category (AD Delegation, Account Security, AD Infrastructure Security, Group Policy Security, Kerberos Security, Entra ID...)
- Score & maturity evolution table
- Exposures evolution table (risk points of each indicator in each report, resolved indicators are grayed)

**One tab per report**

- Report information, security score gauge with the grade and exposures per severity
- Risk points (total and per severity) with the trend compared to the previous report
- Risk points per MITRE ATT&CK tactic
- Score gauge of each category, and comparison with the initial and previous reports
- Improvement & deterioration: exposures resolved and new exposures since the previous report
- All current exposures, indicators that failed to run and ignored exposures

## How are the values computed?

| Value                    | Source                                                                                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Security score**       | Official Purple Knight overall score (0 to 100, higher is better) and grade                                                                                  |
| **Category score**       | Official Purple Knight score of each category (0 to 100, higher is better) and grade                                                                         |
| **Exposure**             | An indicator with the status `Failed` (indicator of exposure or compromise)                                                                                  |
| **Severity**             | Severity of the indicator given by Purple Knight (Critical, High, Medium, Low, Informational)                                                                |
| **ANSSI**                | ANSSI level of the indicator, taken from the ANSSI appendix of the report (Active Directory only). An indicator listed in several levels keeps the lowest one |
| **ANSSI maturity level** | Lowest ANSSI level which still has an exposure, or 5 if no ANSSI indicator is exposed                                                                        |
| **Risk points**          | Computed by the dashboard for each exposure: `indicator weight × (100 - indicator score) / 10`. Higher is worse, like PingCastle points                     |

Purple Knight does not publish the formula of its scores, so the official scores are displayed as is. The risk points are an uncapped metric computed by the dashboard to follow the evolution of the exposures and to take the exceptions into account.

## Handle exceptions

In some cases, Purple Knight can be a little blind or too severe. If you wish, you can add some indicators to the `data\exceptions.csv` file to ignore them in the dashboard. Use the indicator ID displayed by Purple Knight (for example `SI000029`) or its UUID.

If you wish to add the exception to each forest, you can use the wildcard character (*) in the "Domain" column.

Ignored exposures are removed from the risk points, the ANSSI maturity level and the exposure tables, and are listed at the bottom of each report tab. The official Purple Knight scores are not changed.

## How does it work?

A Purple Knight HTML report is a single page application which embeds all its data in JavaScript:

- `window.reportJSON = {...}` contains the general information, the scores per category and the ANSSI appendix
- `window["Category_X"]["<indicator UUID>"] = {...}` contains the result of each indicator

The scripts extract these JSON objects with PowerShell (no browser required). Tested with Purple Knight Community 5.0 on Windows PowerShell 5.1 and PowerShell 7.
